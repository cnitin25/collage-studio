# Sticker images

The sticker palette's images are [Twemoji](https://github.com/jdecked/twemoji)
graphics, copyright Twitter, Inc and other contributors, taken from the
`assets/svg` folder of jdecked/twemoji at tag `v17.0.3`.

They are licensed under the Creative Commons Attribution 4.0 International
licence (CC BY 4.0): https://creativecommons.org/licenses/by/4.0/

Changes: each file's root `<svg>` element was given `width="512"` and
`height="512"`, so that every browser can draw it on a canvas (Firefox can't
draw an SVG without an intrinsic size). The drawings themselves are unchanged.
